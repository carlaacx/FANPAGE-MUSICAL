# FANPAGE-MUSICAL
PAGINA DE FEITA PARA ESTUDOS EM HTML, CSS E JS.    

Esse site é O Fanpage Music, uma página no estilo fanzine retrô dedicada à música clássica e analógica. Combinei a estrutura semântica em HTML, um design personalizado em CSS com cores vintage, e uma interatividade em JavaScript que sugere músicas aleatórias ao clicar no botão. É uma experiência visual e cultural simples, funcional e temática.
